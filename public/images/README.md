# 사진 폴더

이 폴더에 아래 이름으로 사진을 올리면 사이트에 자동으로 나타납니다.
사진이 없는 자리는 회색 박스로 보입니다.

- 확장자: `.jpg` `.jpeg` `.png` `.webp` (대소문자 상관없음)
- 아이폰 HEIC 사진은 안 됩니다 → JPG로 바꿔서 올려 주세요.
- 한 장에 5MB 이하를 권장합니다. 크기·용량은 사이트에서 자동으로 최적화됩니다.

| 파일 이름 | 자리 | 권장 비율 |
| --- | --- | --- |
| `hero.jpg` | 메인 화면 배경 | 가로 16:9 |
| `program-pt.jpg` | 프로그램 · 1:1 PT | 가로 4:3 |
| `program-group.jpg` | 프로그램 · 그룹 PT | 가로 4:3 |
| `program-pilates.jpg` | 프로그램 · 필라테스 | 가로 4:3 |
| `program-free.jpg` | 프로그램 · 자유이용 | 가로 4:3 |
| `trainer-1.jpg` | 트레이너 1번째 | 세로 3:4 |
| `trainer-2.jpg` | 트레이너 2번째 | 세로 3:4 |
| `trainer-3.jpg` | 트레이너 3번째 | 세로 3:4 |
| `gallery-1.jpg`, `gallery-2.jpg`, … | 시설 사진 ("왜 우리 체육관인가요?" 아래) | 가로 4:3 |

시설 사진은 올린 만큼 번호 순서대로 나옵니다. 한 장도 없으면 그 영역은 보이지 않습니다.
비율이 달라도 가운데를 기준으로 잘려서 들어갑니다.

## 올리는 방법 (GitHub 웹)

1. 이 폴더(`public/images`)에서 **Add file → Upload files**
2. 위 이름으로 바꾼 사진을 끌어다 놓기
3. **Commit changes** → 1~2분 뒤 Vercel이 자동으로 다시 배포
